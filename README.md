# Working of Different Languages (8/09/25)


🔹 1. Language Execution Models


| **Type**        | **How It Works**                                   | **Examples**                |
| --------------- | -------------------------------------------------- | --------------------------- |
| **Compiled**    | Source code → Machine code via compiler            | C, C++, Rust, Go            |
| **Interpreted** | Source code → Executed line-by-line by interpreter | Python, Ruby, Bash          |
| **Hybrid**      | Source → Bytecode → VM (JIT optional)              | Java, C#, Julia, JavaScript |



🔹 2. Compiler vs Interpreter


| Feature        | **Compiler**                    | **Interpreter**              |
| -------------- | ------------------------------- | ---------------------------- |
| Execution Time | Faster (compiled ahead of time) | Slower (executed at runtime) |
| Output         | Binary (e.g., `.exe`, ELF)      | No binary, just execution    |
| Error Handling | At compile-time                 | At runtime                   |
| Portability    | Platform-specific               | Platform-independent         |
| Example Tool   | `gcc`, `rustc`, `javac`         | Python, Node.js              |
